# Personal Dashboard - Pertemuan 2 (JavaScript Next Gen ES6+)

Nama: Duwi Putri Wahyuni | NIM: 124140049 | Prodi: Teknik Informatika, ITERA

## Fitur
- Sapaan dinamis + jam real-time
- Profil (class `Profile`)
- Daftar tugas: tambah, selesai, hapus, filter, prioritas (class `TaskManager`, tersimpan di localStorage)
- Ringkasan tugas + progress bar
- Skill (tambah/hapus)
- Kutipan harian (Promise + async/await + try/catch)
- Mode terang/gelap

## Fitur ES6+ yang dipakai
let/const, arrow function, template literals, destructuring, spread/rest, class (getter, private field), object literal shorthand, map/filter/reduce/sort, Promise, async/await, optional chaining `?.` dan nullish `??`.

## Menjalankan
Buka `index.html` di browser (atau Live Server di VS Code).
